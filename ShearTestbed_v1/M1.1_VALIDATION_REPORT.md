## CLARIFICATIONS

### Why Flinc?
- Flinc = KiDS-1000 simulation/mock framework name
- Contains actual cosmic shear ξ± data (NOT galaxy-galaxy lensing)
- Used in KiDS-1000 validation and testing

### Why not FITS?
- FITS file in KCAP contains **Band Powers** (PeeE/PneE), not ξ±
- Different observable, different pipeline
- Flinc ξ± is correct for correlation function analysis

### Data Vector Length
- 195 points (post-cut) vs 270 (pre-cut in other formats)
- Scale cuts already applied in Flinc data file
- This is correct and expected
