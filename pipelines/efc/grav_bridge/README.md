# EFC Grav-Cosmo Bridge Pipeline

**Structural closure of growth-sector couplings between discrete gravity and cosmology.**

This pipeline implements the four-phase empirical test of whether the discrete-gravity prefactor \(C \approx 2.32\) (measured in the Grid-AQUAL sector) can be projected into the cosmological growth equation via multiplicative, local-friction, or non-local-memory-friction couplings.

**Result:** every one of the three coupling classes is either structurally rejected by the data or absorbed by the \(\Omega_m\)-coupling degeneracy once geometry is locked by BAO+\(H(z)\). The growth-only \(E_G\) direction (\(\Sigma=1\)) carries no information independent of \(f\sigma_8\). The paper containing the full result is in `figshare/structural-closure-growth-couplings-2026-04-23/`.

## Quick start

```bash
# Phase 2 sanity (β=0 → FlatLCDM identity, β=±1 asymmetric response)
python scripts/variant_j_sanity.py

# Phase 1 k_Λ sweep: Δχ²(k_Λ) at fixed C=2.32
python scripts/variant_i_klambda_sweep.py

# Phase 2 unrestricted MCMC: Ω_m and β from fσ8 alone (shows degeneracy)
python scripts/variant_j_mcmc.py

# Step 1: BAO+H(z) Ω_m anchor (saves posterior to outputs/)
python scripts/step1_bao_hz_lcdm_mcmc.py

# Step 2: VariantJ with BAO-locked Ω_m prior (degeneracy broken → β collapses)
python scripts/step2_variant_j_with_bao_prior.py

# Step 3: VariantK memory coupling with BAO prior (same null as Step 2)
python scripts/step3_variant_k_with_bao_prior.py

# Phase 4: E_G prediction vs literature (growth-only → redundant with fσ8)
python scripts/phase4_e_g_test.py
```

Each script writes a timestamped JSON summary and NPZ chain to `outputs/`. Step-2/3 also write PNG plots.

## Reproducibility

- Python 3.10+, NumPy 1.x or 2.x, SciPy, emcee 3.1+, matplotlib (plots only).
- All MCMC seeded at 42; sampler `emcee.EnsembleSampler` with 32 walkers × 1500 steps (Steps 2–3) or 16 × 500 (Phase 2 minimal-MCMC demo).
- Each variant passes a numerical identity gate at its null-coupling limit (max \(|\Delta f\sigma_8| < 10^{-10}\) vs FlatLCDM) before MCMC runs.

## The three coupling classes

| Class | Name | Modification | Test result |
|-------|------|--------------|-------------|
| A | `EFCVariantI` | source \(\propto G_{\text{eff}}(k,a)/G \cdot \rho \cdot \delta\) | structurally excluded (k_Λ sweep) |
| B | `EFCVariantJ` | friction \(\propto \beta\, g(a)/a\) | collapses under BAO lock |
| C | `EFCVariantK` | friction \(\propto \beta\, G(a)/a\) with \(G = \int g\) | same null — locality not the issue |

See `docs/PHASES_1_TO_4_RESULT.md` for the full write-up.

## Data provenance

- **BAO:** DESI DR2 (arXiv:2503.14738), 13 measurements with full 13×13 covariance.
- **H(z):** Cosmic chronometers, Moresco et al.
- **fσ8:** 6dFGS (Beutler+2012), SDSS MGS (Howlett+2015), BOSS DR12 (Alam+2017, with Gil-Marín+2020 3×3 covariance), VIPERS (Pezzotta+2017), FastSound (Okumura+2016).
- **E_G literature:** Amon+2018, Reyes+2010, Singh+2019, Blake+2016, de la Torre+2017 (used in `phase4_e_g_test.py` — hard-coded in script).
- **Sound horizon:** Planck 2018, r_d = 147.09 Mpc fixed.
