# Reflection

Structured reflection layer documenting how understanding of EFC evolved over time. Contains formal schema-based entries, chronological logs, and cross-referencing indices.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `reflection/` | Core reflection entries documenting insight formation |
| `reflection-index/` | Index organizing entries for accessibility and cross-referencing |
| `reflection-log/` | Chronological timestamped reflection log |
| `reflection-schema/` | Schema and validation rules for reflection entries |

## Purpose

This layer provides a transparent record of the author's evolving understanding — not the final theory, but the process of arriving at it. Each entry captures what changed, why, and what was learned.
