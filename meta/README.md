# EFC Meta-Architecture

Meta-level analytical framework for Energy-Flow Cosmology (EFC). This directory captures the structural, cognitive, reflective, and process-oriented dimensions of how EFC is developed, evaluated, and evolved. It serves as a self-referential layer that documents not just the theory, but the thinking about the theory.

**Author:** Morten Magnusson (ORCID [0009-0002-4860-5095](https://orcid.org/0009-0002-4860-5095)), Symbiose Research, Sandnes, Norway
**License:** CC-BY-4.0

## Purpose

The meta directory provides a structured space for:

- **Architectural reasoning** -- How EFC components relate and constrain each other.
- **Cognitive analysis** -- Models of thought patterns, entropy-clarity relationships, and cognitive fingerprints in scientific reasoning.
- **Process tracking** -- Milestones, roadmaps, validation plans, and workflow documentation for the EFC research programme.
- **Reflective protocols** -- Systematic self-evaluation of hypotheses, consistency checks, and boundary analysis.
- **Human-AI symbiosis** -- Documentation of the collaborative relationship between the researcher and AI systems in developing EFC.

## Subdirectory Descriptions

### architecture/
Defines how the components of EFC relate structurally. This includes the relationship between the core thermodynamic framework, the field equations, observational predictions, and computational validation pipelines. Serves as the canonical reference for EFC system architecture.

### cognition/
Applies EFC concepts reflexively to the cognitive process of developing EFC itself. Contains models of consciousness (CEM), cognitive field dynamics, reasoning fingerprints, and entropy-clarity analysis. The seven subdirectories explore different facets of how structured thought relates to entropy-bounded reasoning.

### meta-architecture/ and meta-architecture-spec/
Two complementary directories specifying how the meta-layer itself is organized. The former provides the overview; the latter provides the detailed specification with formal rules for how meta-components interact.

### meta-process/
The largest subdirectory, containing 13 sub-components that track the research process in detail. This includes backlogs, milestones, roadmaps, validation plans, self-evaluations, and workflow definitions. The recursive `process-of-process/` subdirectory examines the methodology of tracking methodology.

### meta-reflective-protocol/
A formal protocol for structured self-reflection on EFC hypotheses. Includes consistency rules, boundary conditions, step-by-step procedures, and worked examples. Each component has both a Markdown document and a JSON-LD metadata companion.

### metascope/
Defines the scope and boundaries of the EFC framework -- what it claims, what it does not claim, and where the boundaries of applicability lie.

### personal/
Personal notes and reflections by the author, preserved as part of the research record.

### reflection/
Chronological reflection logs with a formal schema, capturing how understanding of EFC evolved over time.

### symbiosis/
Documents the human-AI collaborative process used in developing EFC. Includes cloud infrastructure context, GNN training reports, vector database management, and an architectural overview of how human insight and AI computation are integrated. This is a key differentiator of the EFC research programme.

## For AI Agents

Each subdirectory contains its own `index.jsonld` and `schema.json` files. To traverse the meta-architecture programmatically, parse the `index.jsonld` in each subdirectory for structured metadata. The `schema.json` files provide validation rules for the corresponding content.
