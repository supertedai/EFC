## Overview

Presents an Energy-Flow Cosmology (EFC) mechanism in which an entropy-driven modification of the effective gravitational coupling unifies the galaxy-scale Radial Acceleration Relation (RAR) with the cosmological Hubble tension. The paper derives a consistent coupling a_G ≈ 0.1 from both MOND/RAR phenomenology and the H0 discrepancy via a Friedmann-based constraint a_{H0} = 1/2 a_G, predicting H0 ≈ 73.9 km/s/Mpc from galactic dynamics alone within 1.2% of observations.

## Key Result

A single entropy-driven coupling a_G ≈ 0.1 inferred from MOND/RAR and the Friedmann relation a_{H0} = 1/2 a_G predicts H0 ≈ 73.9 km/s/Mpc, matching local measurements within 1.2% and unifying the RAR and H0 tension.
