# Archived paper directories

This directory contains paper packages that are superseded but preserved for
provenance. They are excluded from the doi-map generator and the maintenance
pipeline.

## Contents

### `efc_master/`
EFC — Master Specification, v1.0, dated 2025-11-15. Pre-DOI working draft.
Superseded by `efc_master_v1/` (then by `efc_formal_spec/`).

### `efc_master_v1/`
Energy-Flow Cosmology (EFC) Master Specification v1.1, dated 2025-11-16.
First DOI-tagged release on figshare DOI `10.6084/m9.figshare.30630500`.
Already labelled `(v1 Archive)` in the Symbiose Qdrant collection. Superseded
by `efc_formal_spec/` which carries the same DOI but is the active canonical
copy.

## Canonical for DOI 30630500

The active record for `10.6084/m9.figshare.30630500` is
`docs/papers/efc/efc_formal_spec/`. That directory's `index.json` is what the
public ledger and rootfiles reference; this archive exists only to preserve
the development trail.
