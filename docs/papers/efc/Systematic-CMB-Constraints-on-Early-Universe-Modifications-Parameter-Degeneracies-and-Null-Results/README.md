## Overview

Implements two Energy-Flow Cosmology (EFC) mechanisms in CLASS—(i) a smooth modification to the photon–baryon coupling \dot{\kappa}(z) and (ii) a Gaussian-windowed, radiation-like background energy fraction \epsilon at recombination—and tests them against the Planck 2018 CMB TT spectrum with amplitude marginalization. A 2D parameter analysis shows both mechanisms yield null results once degeneracies with h are accounted for, turning an apparent 1D “detection” into a parameter-degeneracy artifact.

## Key Result

Both tested EFC mechanisms are rejected by Planck 2018 TT once parameter covariances are accounted for; the apparent 1D signal for \epsilon vanishes in a 2D (\epsilon, h) analysis with the minimum at \epsilon≈0.
