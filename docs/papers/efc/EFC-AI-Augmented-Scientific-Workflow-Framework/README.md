## Overview

Defines a structured framework for integrating large language models into scientific workflows while preserving human control, accountability, and reproducibility. It formalizes four core mechanisms—Question Architecture (QA), Entropy Navigation (EN), Reflective Scaffolding (RS), and Strict Separation of Roles (SR)—to ensure transparent provenance, machine-readable intent, entropy-guided exploration, and external grounding of AI reflections. The work aligns with FAIR principles and emphasizes a human validation gate for all scientific claims.

## Key Result

The paper formalizes a human-governed AI workflow centered on QA, EN, RS, and SR to deliver reproducible, traceable, and accountable AI-assisted research.
