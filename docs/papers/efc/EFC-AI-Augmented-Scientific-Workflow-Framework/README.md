# EFC — AI-Augmented Scientific Workflow Framework

**DOI:** [10.6084/m9.figshare.30636863](https://doi.org/10.6084/m9.figshare.30636863)

This directory contains the paper describing the AI-augmented research
framework used in the Energy-Flow Cosmology project. It defines the role
of human reasoning, LLM-structure, validation layers and reproducible
metadata within a unified scientific workflow.

**Included files**
- PDF (authoritative)
- Markdown (readable)
- JSON-LD metadata
- Local schema
- Machine index
- Citations file
