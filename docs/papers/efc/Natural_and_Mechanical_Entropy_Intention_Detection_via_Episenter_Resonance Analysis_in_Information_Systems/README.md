## Overview

Defines an operational, agent-free measure of structural intention as the KL-divergence between observed outputs and a system’s own baseline dynamics. Proposes an episenter–resonance detection framework with three diagnostics (episenter concentration, resonance spectrum ratio, cross-regime asymmetry) to distinguish natural from mechanically injected entropy, and outlines case studies and an empirical protocol for LLMs with falsifiable predictions.

## Key Result

Introduces a three-diagnostic episenter–resonance methodology that operationalises intention via KL-divergence and provides a falsifiable, regime-bound protocol to distinguish natural from mechanical entropy; empirical execution is proposed but not yet performed.
