## Overview

Synthesis note introducing a single-integral decomposition of observed cosmological redshift in Energy-Flow Cosmology using an effective entropy field Seff and a unifying regime scale aG. It links three observational windows—TCMB(z), the cosmic distance-duality relation η(z), and structural S(z) consistency—under one parameter with explicit projections (aH0 = aG/2, ac = aG/4), and recovers ΛCDM when ∇Seff → 0.

## Key Result

Provides a unified line-integral redshift decomposition tied to a single regime scale aG that simultaneously constrains three observational windows and predicts CDDR deviations |η(z)−1| ~ 10^-3–10^-2 (up to ~5×10^-2 in saturation), while reducing to ΛCDM when ∇Seff → 0.
