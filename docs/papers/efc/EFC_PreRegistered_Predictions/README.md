## Overview

This preregistration freezes and publicly archives the Energy-Flow Cosmology (EFC) model’s benchmark parameters, EFT mapping, and a sealed set of testable observational predictions prior to Euclid DR1, Rubin DP2, and SO×Euclid releases. It specifies percent-level shifts of key observables relative to ΛCDM on Euclid quasi-linear scales, the characteristic µ<1, Σ>1, η>1 signature, and explicit kill criteria, all anchored by DOIs and a SHA-256 hash.

## Key Result

All EFC benchmark parameters and opposite-sign growth–lensing predictions are preregistered and sealed, with specific percent-level shifts (P1–P5) vs. ΛCDM on Euclid DR1 scales and the characteristic signature µ<1, Σ>1, η≈1.10.
