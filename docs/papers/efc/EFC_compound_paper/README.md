## Overview

This paper analyzes how the sealed EFC lensing engine’s Σ_eff(z) crossover is controlled by model parameters and cross-validates robustness across power-spectrum choices. It finds that the kinetic stiffness scale K0 dominantly sets the redshift of the predicted sign-changing lensing coupling (z× ≈ 0.44), while amplitude parameters have minor impact, and documents qualitative µ < 1 agreement between the lensing and growth sectors. It pre-registers a falsification framework linking the non-monotonic lensing signature to growth and EG tests for upcoming Euclid DR1 and DESI DR2 data.

## Key Result

K0 is the dominant control on the Σ_eff(z) crossover redshift (Δz ≈ 0.87 over K0 ∈ [0.5, 4.0]), while joint ×50 amplitude rescaling changes the crossover by only Δz ≈ 0.11; the sign-changing prediction is robust to BBKS transfer-function choice (shift ≥ 0.06) and both sectors predict µ < 1.
