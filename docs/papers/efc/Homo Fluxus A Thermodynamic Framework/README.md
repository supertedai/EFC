## Overview

Proposes a thermodynamic substrate for cognition in which local entropy minimization via coherent information flow underlies consciousness, affect, ethics, and AI alignment. Introduces Homo Fluxus (agent-as-node-in-flow) and systemic empathy (field-coupled coherence sensitivity), and specifies operational proxies for a coherence potential with falsifiable, cross-scale predictions.

## Key Result

Defines Homo Fluxus and systemic empathy as consequences of an EFC-based coherence potential, proposes measurable proxies that must co-vary as a single latent factor, and outlines falsifiable predictions linking consciousness, affect, cooperation, and alignment.
