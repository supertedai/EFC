# EFC — Grid-Higgs Framework

**DOI:** [10.6084/m9.figshare.28559510](https://doi.org/10.6084/m9.figshare.28559510)

This directory contains the paper introducing the Grid-Higgs Framework:
a structural model describing how grid-level resistance, energy flow,
and entropy gradients produce Higgs-like mass effects without appealing 
to particle-field interactions.
