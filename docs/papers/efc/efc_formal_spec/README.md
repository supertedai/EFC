## Overview

This paper presents the formal mathematical specification of Energy-Flow Cosmology (EFC). It defines the entropy field S(x), the energy–flow field Ef(x), an entropy-coupled effective potential Φ(Ef, S), and an entropy-dependent effective light speed c(S), showing how rotation curves, light-travel times, and lensing emerge from their coupling.

## Key Result

Provides a self-contained formalism in which dynamics and observables co-emerge from an entropy field via Φ(Ef, S) and an entropy-dependent propagation law c(S).
