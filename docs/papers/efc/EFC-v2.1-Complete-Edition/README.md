**DOI:** [10.6084/m9.figshare.30478916](https://doi.org/10.6084/m9.figshare.30478916)

Energy-Flow Cosmology framework.

integrating structure, dynamics, entropy behaviour, grid interactions,
field mappings, and the full conceptual architecture into a unified,
version-controlled specification.

matured theory as used in current documentation, software, and the
semantic graph.
