# EFC — Hypothesis: Interrelation Between Energy and Entropy

**DOI:** [10.6084/m9.figshare.28557281](https://doi.org/10.6084/m9.figshare.28557281)

This directory contains the paper presenting the hypothesis that energy
flow and entropy gradients are interdependent components of a unified
thermodynamic field. The paper outlines how their interaction shapes
structure, dynamics, information propagation, and spacetime behaviour
within the EFC framework.
