## Overview

This paper computes the CMB–galaxy ISW cross-correlation C_ell^{Tg} for Energy-Flow Cosmology (EFC) using linear perturbation theory and DESI DR1–motivated tracer windows over multipoles ell=2–60. It introduces a bounded cancellation index C that isolates opposite-sign contributions from the standard ISW kernel and an EFC transition kernel driven by a time-varying gravitational coupling mu(a). The key prediction is a strong, redshift-dependent suppression of the ISW amplitude near the EFC transition epoch (z_t ≈ 0.82), providing clear falsifiable tests against ΛCDM.

## Key Result

EFC predicts strong redshift-dependent cancellation (high C) between K_mu and K_mu' near z_t ≈ 0.82, suppressing the ISW amplitude (AISW ≈ 0.3–0.6) relative to ΛCDM, with current measurements consistent within ~1.6σ.
