## Overview

Introduces Energy-Flow Cosmology (EFC), a thermodynamic framework in which a continuous energy-flow potential Ef and a normalized entropy field S ∈ [0,1] jointly govern physics. GR and QFT emerge as limiting behaviors as S → 0 and S → 1, respectively, with an entropy-dependent effective light speed c(S) linking macroscopic curvature and microscopic quantization. The paper outlines observable implications for cosmology, including lensing without dark matter, Hubble-tension reinterpretation, and measurable deviations in c under extreme field conditions.

## Key Result

Proposes a unified, non-equilibrium thermodynamic field theory in which an entropy-dependent light speed c(S) and an energy-flow potential Ef make GR and QFT emergent boundary regimes and recast dark sector anomalies as entropic stresses.
