## Overview

Paper III introduces Energy-Flow Cosmology (EFC), a thermodynamic framework in which entropy-gradient-driven energy flow governs regime-dependent structure formation across scales. Using a phenomenological decomposition E_total = E_flow + E_latent, the paper provides a unified interpretation consistent with the three-regime behavior seen in SPARC rotation curves (Paper I) and the early-time galaxy abundance excesses in JWST COSMOS-Web (Paper II), and it outlines testable predictions without replacing ΛCDM.

## Key Result

A single entropy-gradient-driven framework (EFC) consistently organizes both the three-regime behavior in galactic rotation curves and the accelerated early-universe structure formation seen by JWST.
