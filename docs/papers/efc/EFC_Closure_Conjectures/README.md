## Overview

Proposes two closure relations for Energy-Flow Cosmology (EFC): the transition acceleration g† = c H0 / e and a galactic phase factor C = 2e − 1, both motivated by the Core Lock exponential structure. Using SPARC-derived g†, the paper predicts H0 = 70.2 ± 16.8 km/s/Mpc, consistent with Planck, SH0ES, and TRGB within current uncertainties. The conjectures are framed with explicit falsification criteria and remain to be validated by higher-precision measurements.

## Key Result

The closures g† = cH0/e and C = 2e − 1 are consistent with SPARC-inferred g† and yield H0 = 70.2 ± 16.8 km/s/Mpc, within 1σ of Planck, SH0ES, and TRGB.
