This paper tests three operator-level ways for Energy-Flow Cosmology (EFC) to couple a discrete-gravity prefactor to the linear growth of structure: multiplicative Geff on the Poisson source, additive local friction, and additive non-local (memory) friction. Using DESI DR2 BAO, cosmic-chronometer H(z), an fσ8 compilation, and the EG statistic, it shows each class is either structurally excluded or fully degenerate with Ωm once geometry is locked, implying growth-only observables cannot discriminate this theory class.

## Key Result

All three tested growth-sector coupling classes (multiplicative Geff, additive local friction, additive non-local memory friction) are either structurally excluded by the data or fully absorbed by the Ωm–coupling degeneracy once geometry is fixed by BAO+H(z); EG with Σ=1 adds no information beyond fσ8.
