## Overview

Tests three operator-level ways Energy-Flow Cosmology could couple to the linear growth equation: multiplicative Geff in the Poisson term, additive local friction, and additive non-local (memory) friction. Using DESI DR2 BAO, cosmic-chronometer H(z), fσ8, and EG data, it shows each class is either structurally excluded or degenerate with Ωm once geometry is locked, implying growth-only observables cannot discriminate this theory class and pointing to lensing/slip or cross-correlations as the next informative directions.

## Key Result

All three tested coupling classes (multiplicative Geff, local friction, non-local memory friction) are either structurally excluded by the data or absorbed by the Ωm–coupling degeneracy once geometry is locked by BAO+H(z); EG with Σ=1 adds no information beyond fσ8.
