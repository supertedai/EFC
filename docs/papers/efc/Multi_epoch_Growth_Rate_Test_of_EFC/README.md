## Overview

First multi-epoch empirical test of the Energy-Flow Cosmology (EFC) perturbation-sector coupling using 14 fσ8(z) measurements from 6dFGS, BOSS DR12, eBOSS DR16, and DESI DR1. The study solves the full linear growth ODE with a regime-dependent gate μ(a)=1−B·T(a) and finds a null result: ΛCDM fits slightly better than EFC while EFC remains consistent within current errors, highlighting a strong Ωm–B degeneracy that requires BAO to break.

## Key Result

ΛCDM provides an excellent fit and is marginally preferred over EFC, while EFC with μ0 in the survival valley remains fully consistent with current fσ8(z) data.
