## Overview

This preregistration freezes an Energy-Flow Cosmology (EFC) prediction for the EG gravitational-slip statistic to be tested with the Simons Observatory (SO) CMB lensing cross-correlated with Euclid DR2 galaxy data. It specifies the predicted enhancement EG^EFC / EG^GR = 1.086 ± 0.012 at kc ≈ 0.05 h Mpc−1 and z ≈ 0.5, the dataset and estimator regime, and binding pass/fail (kill) criteria.

## Key Result

Sealed preregistered prediction that SO × Euclid DR2 will measure EG_obs / EG_GR = 1.086 ± 0.012 at kc ≈ 0.05 h Mpc−1, z ≈ 0.5, with a pass window [1.03, 1.14] and a fail (kill) condition at EG_obs / EG_GR = 1.00 ± 0.01 (>3σ).
