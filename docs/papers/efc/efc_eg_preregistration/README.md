## Overview

This sealed pre-registration specifies the Energy-Flow Cosmology (EFC) prediction for the EG gravitational-slip statistic to be tested with the Simons Observatory LAT × Euclid DR2 cross-correlation. It forecasts an 8.6% enhancement of EG relative to the GR/ΛCDM pipeline baseline from jointly predicted µ < 1 (growth suppression) and Σ > 1 (lensing enhancement), and fixes pass/fail windows and a binding falsification (kill) criterion prior to data availability.

## Key Result

Sealed pre-registration of an EFC prediction that EG will be enhanced by 8.6% ± 1.2% over the GR pipeline baseline in SO × Euclid DR2, with fixed pass/fail windows and a binding kill criterion.
