## Overview

Symbiosis presents a human–AI co-reflection architecture that couples large language models with a hybrid memory substrate—Neo4j for knowledge graphs, Qdrant for vector search—and a unified API with structured reflection/logging. The system is designed to enable persistent, traceable, and metacognitively informed long-horizon reasoning, demonstrated through multi-year Energy-Flow Cosmology (EFC) research use.

## Key Result

Introduces and operationalizes a hybrid graph–vector memory architecture with structured reflection/logging that supports persistent, traceable human–AI co-reasoning over long time scales, demonstrated on multi-year EFC research.
