## Overview

This research note tests the Energy-Flow Cosmology (EFC) modified background expansion against precision BAO data using the official BOSS DR12 consensus likelihood with the full 6×6 covariance matrix. With DESI DR2-calibrated EFC parameters held fixed (no refitting), EFC attains a modest improvement over ΛCDM (Δχ² ≈ −2.36) and passes a stringent, reproducible covariance-aware BAO consistency test; results are cross-checked with cosmic chronometer H(z) data.

## Key Result

With parameters fixed to DESI DR2-calibrated values, EFC achieves a modest improvement over ΛCDM on BOSS DR12 BAO with full covariance and passes this stringent consistency test without parameter retuning.
