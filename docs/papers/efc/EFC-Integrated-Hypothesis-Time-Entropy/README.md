## Overview

Proposes an Energy-Flow Cosmology (EFC) in which time emerges from energy-flow dynamics modulated by entropy within a Grid-Higgs spacetime. The work links energy flow Ef(S), a variable light speed c(S), and an emergent time relation t(k, S, dEf/dt), and replaces dark matter with halo-mediated entropy regulation. It outlines falsifiable predictions for CMB small-scale anisotropies, gravitational lensing in low-entropy regions, and nHz gravitational-wave propagation effects, while noting the need to calibrate key constants and test relativity compatibility.

## Key Result

Within the Grid-Higgs framework, time emerges from the entropy-modulated energy flow, with qualitative consistency claimed for a ~0.05% CMB TT excess at l≈2500, enhanced lensing in low-entropy regions, and GR-consistent GW speeds with nHz-scale testable deviations.
