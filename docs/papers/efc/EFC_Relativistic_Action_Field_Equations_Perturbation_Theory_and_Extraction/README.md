## Overview

Derives the full field equations of the EFC relativistic action with a non-minimal coupling F(ϕ)R, density-dependent kinetic stiffness K(ρ), and a flow constraint enforced by a Lagrange multiplier. Performs linear perturbation theory in conformal Newtonian gauge and provides closed-form, quasi-static expressions for the effective couplings µ(k, z), Σ(k, z), and slip η(k, z), while showing cT = c and predicting a modified GW amplitude (dL^GW ≠ dL^EM).

## Key Result

In the quasi-static sub-horizon regime, EFC yields µ < 1, Σ > 1, and η ≠ 1 from a single action, with cT = c exactly and a predicted GW amplitude modification (dL^GW ≠ dL^EM).
