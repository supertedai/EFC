## Overview

Tests whether a discrete entropic gravity operator with MOND-like infrared enhancement remains compatible with cosmological structure growth when its transition scale is Λ-locked. Embeds a scale-dependent Geff(k) into the linear growth equation and compares Λ-locked (super-Hubble) versus sub-Hubble transition scales. Finds that only Λ-locking (LΛ ≳ H0−1) preserves realistic σ8 ≈ 0.81; sub-Hubble transitions cause catastrophic overgrowth.

## Key Result

Only the Λ-locked transition (LΛ ≈ 4.4 Gpc, kΛ ≈ 0.0014 h/Mpc) preserves σ8 ≈ 0.81 (0.4% above ΛCDM), while sub-Hubble transitions (10 Mpc and 1 Mpc) produce explosive overgrowth (σ8 ≫ 1), establishing LΛ ≳ H0−1 as necessary for viability.
