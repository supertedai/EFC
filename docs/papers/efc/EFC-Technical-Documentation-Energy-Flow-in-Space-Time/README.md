## Overview

Technical documentation outlining the Energy-Flow Cosmology (EFC) view that ongoing energy flow sustains and shapes space-time. It organizes the framework’s core principles, references observational touchpoints (redshift and the CMB), sketches a mathematical program (with entropy and c as boundary conditions), and lists applications and open challenges.

## Key Result

The document presents a conceptual framework in which energy flow sustains and shapes spacetime, drives the present moment, interacts with entropy, and is bounded by the speed of light, with qualitative links to redshift and CMB observations.
