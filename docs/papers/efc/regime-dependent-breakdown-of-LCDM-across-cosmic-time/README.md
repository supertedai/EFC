## Overview

Combines low-z galaxy dynamics (SPARC) with high-z galaxy abundances (JWST COSMOS-Web) to test whether deviations from standard ΛCDM predictions cluster by observational regime. Using a descriptive L0–L3 taxonomy and a pre-specified chi-squared/permutation framework, the paper finds significant, monotonic high-z excesses and structured low-z rotation-curve deviations, rejecting uniform randomness (χ²=47.3, df=4, p≈1.3e-9). The result is robust to photometric-redshift resampling and conservative systematic stress tests.

## Key Result

Deviation signals cluster by regime with χ²=47.3 (df=4, p≈1.3×10⁻⁹), and high-z galaxy abundances rise monotonically above predictions (≈23–529× vs Behroozi; exceeding halo limits for z>8), robust to photo-z resampling and conservative systematics.
