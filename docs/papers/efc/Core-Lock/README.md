## Overview

Specifies the Core Lock dynamical engine for Entropy-Bounded Empiricism (EBE): a running grid-state parameter f(S) with constant negative beta function that uniquely yields an exponential form and a conserved information length. Physical observables project through an accumulated phase Φ(S), producing a proxy-independent, falsifiable prediction that any detected variations in constants must exhibit a constant log–log correlation slope d ln v / d ln c = constant. Current null results constrain couplings but do not falsify the framework absent a specified projection.

## Key Result

A constant beta function in S enforces an exponential f(S) and yields a falsifiable, proxy-independent correlation prediction d ln v / d ln c = constant, with current null results constraining couplings but not the engine.
