## Overview

Defines a governance-centered framework for integrating large language models into scientific workflows while preserving human control, accountability, and reproducibility. It formalizes four core mechanisms—Question Architecture, Entropy Navigation, Reflective Scaffolding, and Strict Separation of Roles—and couples them with provenance, versioning, and machine-readable metadata to enable transparent, traceable research.

## Key Result

Version 1.2 formalizes a human-governed AI workflow built on QA, EN, RS, and SR to deliver transparent, reproducible, and accountable scientific research outputs.
