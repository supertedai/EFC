## Overview

Canonical master specification for Energy-Flow Cosmology (EFC), defining the formal structure and baseline equations for three tightly coupled layers: EFC-S (structural/halo), EFC-D (energy-flow dynamics), and EFC-C0 (entropy–information capacity mapping). The paper fixes notation, establishes the central energy-flow potential Ef = ρ(1−S), and provides the compact mathematical core that all higher-level EFC models, simulations, and epistemic layers reference.

## Key Result

EFC is formally specified as a three-layer thermodynamic-information framework (EFC-S, EFC-D, EFC-C0) that derives gravitational dynamics, halo structure, and expansion history from a single energy-flow potential Ef = ρ(1−S) without invoking dark matter or dark energy.
