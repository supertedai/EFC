## Overview

Extends Kill-Test v6 (probe-2) from 5 hand-refitted SPARC galaxies to the full SPARC 175 sample, fitting a 3-parameter EFC phenomenological rotation-curve model against a 2-parameter NFW halo using differential evolution and AIC for model comparison. On 171 galaxies with ≥5 data points, EFC wins 60.2% (median ΔAIC = +6.21), ties 26.9%, and loses 12.9%, with median χ²_red of 0.44 (EFC) vs 1.69 (NFW). Regime separation (FLOW > LATENT) is highly significant and no mass-scale dependence of ΔAIC is detected, refuting cherry-picking and supporting single-component universality.

## Key Result

Across 171 SPARC galaxies (≥5 points), the 3-parameter EFC curve outperforms 2-parameter NFW in 60.2% of cases by AIC (median ΔAIC = +6.21), ties 26.9%, and loses 12.9%, with median χ²_red of 0.44 (EFC) vs 1.69 (NFW) and strong FLOW>LATENT separation (Mann–Whitney p ≈ 0) without mass dependence (ρ = 0.11, p = 0.15).
