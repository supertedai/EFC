## Source code

| File | Role |
|---|---|
| `src/sparc175_killtest_universality.py` | Standalone Python pipeline. Reads `sparc_rotation_curves.dat`, fits EFC and NFW to each galaxy with `scipy.optimize.differential_evolution` (seed = 42), computes `χ²_red`, `AIC`, `ΔAIC = AIC_NFW − AIC_EFC`, classifies regime (FLOW / TRANSITION / LATENT), assigns verdict (EFC_decisive / EFC / tied / LCDM / LCDM_decisive), runs Mann-Whitney and Spearman tests, writes `data/sparc175_killtest_results.json`. Depends on numpy and scipy only. |

## Not included in this package

- Raw SPARC rotation-curve data. Read directly from the parent paper
  `../Comprehensive-analysis-of-175-SPARC-galaxies-.../sparc-n175-extended/sparc_rotation_curves.dat`
  (3391 rows, 175 galaxies, Lelli+2016 Rotmod_LTG format).
- Multi-component EFC fits with fixed `(K0, m²)`. This is the open
  question #1 in `README.md` and the subject of a follow-up package.

## Dependencies

- Python ≥ 3.10
- numpy ≥ 1.24
- scipy ≥ 1.10 (for `differential_evolution`, `spearmanr`, `mannwhitneyu`)

No network access, no external services, no trained models. Runs on any
machine with a standard scientific-Python install in under 2 minutes.
