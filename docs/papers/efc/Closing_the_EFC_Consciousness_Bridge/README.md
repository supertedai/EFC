## Overview

Introduces a dimensionless, regime-indexed mapping from the EFC entropy field S to cognitive variables (Omega-hat, kappa-hat), derives coupled dynamical equations that make the Omega–kappa anti-correlation intrinsic, and replaces the separable product C=Omega*kappa with a single-parameter non-separable functional. The framework closes the cosmology-to-cognition bridge, inherits a cross-domain constant K=4.4±0.6 from SPARC rotation curves, and shows qualitative consistency with propofol sedation EEG.

## Key Result

A closed, dimensionless EFC-to-cognition bridge yields an intrinsic Omega–kappa anti-correlation and a one-parameter non-separable consciousness functional, qualitatively consistent with propofol EEG while inheriting K=4.4±0.6 from SPARC.
