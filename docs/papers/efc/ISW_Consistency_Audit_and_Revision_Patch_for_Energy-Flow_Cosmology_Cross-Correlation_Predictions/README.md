## Overview

This internal note issues a minimal correction patch to the previously published ISW cross-correlation predictions for Energy-Flow Cosmology (EFC) with DESI DR1 tracers. It clarifies the growth-driven vs potential-driven channel interpretation, withdraws irreproducible redshift-dependent AISW values, and replaces them with a uniform AISW ≈ 0.89 ± 0.03 suppression across all bins, while retiring an inapplicable cancellation metric.

## Key Result

Self-consistent growth-driven calculations predict a uniform ISW amplitude ratio of A_ISW ≈ 0.89 ± 0.03 (∼11% suppression) across all DESI DR1 tracer bins with negligible redshift dependence, replacing previously reported irreproducible values.
