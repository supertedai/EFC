## Overview

Proposes that the Hubble tension is an environmental regime mismatch: early-universe background probes (CMB/BAO) measure G0, while late-universe distance-ladder probes inside collapsed structures measure Geff = G0 exp(aG·ΔΦ) > G0. Using the Friedmann scaling, the model predicts ln(Hstructure/Hbackground) = 0.5 aG ΔΦ, yielding a ratio 1.083 and H0,structure = 73.0 km/s/Mpc from H0,background = 67.4, without invoking a global time variation of G.

## Key Result

Interpreting the Hubble tension as a regime mismatch yields Hstructure/Hbackground = exp(0.5 aG ΔΦ) = 1.083, predicting H0,structure = 73.0 km/s/Mpc from 67.4 km/s/Mpc with aG ≈ 0.094 and ΔΦ ≈ 1.71.
