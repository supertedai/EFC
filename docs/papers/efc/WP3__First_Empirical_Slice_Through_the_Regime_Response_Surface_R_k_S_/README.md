## Overview

First cartographic measurement of the gravitational response coordinate R(k,S) along the RSD trajectory using 12 fσ8(z) points from BOSS DR12, eBOSS DR16, and DESI Y1. The analysis finds R(k≈0.13 h/Mpc, S≈0.30) ≈ +0.30, while ΛCDM (R=0) remains preferred by AIC (ΔAIC = −3.8). This work inaugurates an atlas of the response surface, emphasizing mapping over model validation.

## Key Result

Measured a cartographic coordinate on the response surface: R(k≈0.13 h/Mpc, S≈0.30) ≈ +0.30, while ΛCDM is preferred by AIC (ΔAIC = −3.8).
