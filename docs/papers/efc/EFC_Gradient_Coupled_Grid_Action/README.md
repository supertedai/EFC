## Overview

Presents a minimal three-term Lagrangian for a discrete grid coupled to gravity via a gradient interaction |∇Φ|(∇ξ)². The coupling yields a position-dependent stiffness κ_eff = κ0 + α g and a local dispersion relation that, in the gravitational regime, implies E = ℏω ∝ √g, deriving the EFC screening relation from first principles and establishing operator uniqueness within a defined class.

## Key Result

Within a minimal EFT, the unique leading-order local scalar coupling |∇Φ|(∇ξ)² yields κ_eff = κ0 + α g and E ∝ √g in the gravitational regime, providing a first-principles derivation of the EFC screening relation and eliminating alternative operators by symmetry, dimensional, and data-consistency arguments.
