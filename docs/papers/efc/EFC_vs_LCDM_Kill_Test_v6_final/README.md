## Overview

Comprehensive kill-test of Energy-Flow Cosmology (EFC) versus ΛCDM across six probes from galaxy rotation curves to CMB, BAO, and SNe. Using a single action with two global field parameters (K0, m^2), EFC jointly predicts μ≈0.94 and Σ≈1.05 from one mechanism (stiffness + slip) and achieves Δχ^2 ≤ 0 across four cobaya minimize runs. The results indicate EFC cannot be rejected by current data; full MCMC with Bayes evidence is identified as the remaining decisive test.

## Key Result

Across six probes and four cobaya minimize runs, EFC with two global parameters (K0 ≈ 1.55–1.68, m^2 ≈ 0.0032–0.0038) delivers μ≈0.94 and Σ≈1.05 and achieves Δχ^2 ≤ 0 versus GR/ΛCDM; EFC cannot be rejected by current data.
