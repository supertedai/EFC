## Overview

Working note extending Grid-Rendering Cosmology (GRC) to the double-slit experiment with an exact ultraviolet (UV) cutoff formulation arising from a discrete grid scale lg. It derives the deviation from standard QM as an omitted high-k band and shows that for Gaussian slit profiles the deviation is exponentially suppressed, withdrawing a prior polynomial ansatz. The paper relocates testable distinctions to entropy-sensitive decoherence via a clarity function C(S) and to higher-order measurement statistics, noting an open gap in the operational definition of local entropy S.

## Key Result

In GRC the double-slit deviation from QM is exactly the omitted high-k band due to a grid UV cutoff, yielding exponentially suppressed differences for Gaussian apertures and withdrawing the prior O((l_g/d)^2) polynomial ansatz.
