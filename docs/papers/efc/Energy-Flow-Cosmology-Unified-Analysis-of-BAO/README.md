## Overview

Unified empirical test of Energy-Flow Cosmology (EFC) against BAO, SN Ia, and RSD. The effective gravitational coupling μ(a)=Geff/G is derived from the EFC field equation via an entropy field S(a), with background fixed to ΛCDM (γ=0). With one free amplitude (β=0.16) and fixed transition hyperparameters, EFC reproduces BAO/SN and yields a mildly worse but statistically compatible RSD fit (Δχ²≈+1.7), showing no geometry–growth tension in this first-pass regime-consistency check.

## Key Result

With γ=0 and a derived μ(a)=1+βS(a), EFC matches BAO and SN Ia as in ΛCDM and yields a mildly worse but statistically compatible RSD fit, indicating no geometry–growth tension.
