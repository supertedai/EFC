## Overview

Propagates redshift-space distortion (RSD) constraints on the effective gravitational coupling into parameter-locked predictions for galaxy cluster abundances under Energy-Flow Cosmology (EFC). With no parameters fit to cluster data and high-z (CMB) normalization, the paper predicts a +6.4% total cluster excess vs. ΛCDM and a distinctive negative tilt in the redshift-distribution shape ratio R(z), providing sealed, falsifiable targets for eRASS1.

## Key Result

With \alpha_{L2}=0.34 from BOSS DR12 RSD and high-z normalization, EFC predicts N_EFC/N_\LambdaCDM = 1.064 and a negative dR/dz shape tilt (∼+5% at z≈0.15 to ∼−6% at z≈0.7) for eRASS1-like cluster samples, without fitting any parameters to cluster data.
