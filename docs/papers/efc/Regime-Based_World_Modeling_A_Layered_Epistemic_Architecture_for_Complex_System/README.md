## Overview

Introduces Regime-Based World Modeling (RBWM), a meta-epistemic framework that maps scientific claims onto a two-axis coordinate system: the Regime axis (R) for emergent complexity levels and the Epistemic Layer axis (L) for derivation distance from observation. It generalizes the Regime-Gating Principle, asserting that claims are valid only when expressed in driver-near variables for the operative regime, thereby preventing regime leakage and clarifying conflicts between models operating at different epistemic coordinates.

## Key Result

RBWM formalizes a two-axis (R,L) mapping with a regime-gating rule that enforces driver-near variables for validity, exposing regime leakage and reconciling apparent theory conflicts as coordinate mismatches.
