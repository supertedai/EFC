## Overview

A pilot-scale analysis applying Energy-Flow Cosmology (EFC) to 20 SPARC galaxies spanning diverse morphological types, demonstrating regime-dependent validity where EFC achieves 100% success for LSB and dwarf galaxies but systematically underperforms for barred spirals. Introduces the EFC-R (Regime) framework decomposing total energy as Etotal = Eflow + Elatent to delineate EFC's domain of validity, supported by a statistically significant correlation (Spearman ρ = 0.705, p = 0.0005) between structural complexity and EFC performance.

## Key Result

EFC achieves 100% success rate for LSB and diffuse dwarf galaxies but 0% for barred/disturbed spirals, with a statistically significant Spearman correlation (ρ = 0.705, p = 0.0005) between structural complexity and EFC performance, motivating the regime-dependent EFC-R framework.
