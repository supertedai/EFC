## Overview

A pilot-scale analysis applying Energy-Flow Cosmology (EFC) to 20 SPARC galaxies spanning diverse morphological types, revealing regime-dependent validity where EFC achieves 100% success for LSB and diffuse dwarf galaxies but systematically underperforms for structurally complex systems. Introduces the EFC-R (Regime) framework with the decomposition E_total = E_flow + E_latent to delineate EFC's domain of validity.

## Key Result

EFC achieves 100% success rate for LSB and diffuse dwarf galaxies but 0% for barred/disturbed systems, with a statistically significant correlation between structural complexity and EFC performance (Spearman ρ = 0.705, p = 0.0005).
