## Overview

A pilot-scale analysis of Energy-Flow Cosmology (EFC) applied to 20 SPARC galaxies, demonstrating regime-dependent validity where EFC achieves 100% success for LSB and diffuse dwarf galaxies but systematically underperforms for structurally complex systems like barred spirals. Introduces the EFC-R framework with the decomposition E_total = E_flow + E_latent as a domain-of-validity layer for EFC.

## Key Result

EFC achieves 100% success rate for LSB and diffuse dwarf galaxies but 0% for barred/disturbed spirals, with structural complexity (latent field proxy) correlating with EFC performance at Spearman ρ = 0.705, p = 0.0005.
