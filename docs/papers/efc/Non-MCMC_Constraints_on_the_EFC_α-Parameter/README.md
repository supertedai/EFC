## Overview

Validation note reporting non-MCMC constraints on the EFC α-parameter using DESI Y1 and BOSS DR12 BAO, multi-epoch growth-rate (fσ8), IllustrisTNG cluster statistics, and cosmic chronometer H(z) data. Cross-validation and likelihood-ratio tests show a consistent directional preference for EFC over ΛCDM (e.g., Δχ2DESI = −22.01; Δχ2BOSS = −7.77) and a growth-derived indication α = −1.00 ± 0.46 (2.20σ), while concurrent MCMC remains degeneracy-limited. Results are framed as model-comparison metrics (not posteriors) and compared against pre-registered sealed predictions.

## Key Result

Non-MCMC model-comparison metrics consistently prefer EFC over ΛCDM in BAO and growth probes (Δχ2DESI = −22.01; Δχ2BOSS = −7.77; α = −1.00 ± 0.46 from fσ8), while MCMC posteriors remain degeneracy-limited and uninformative for α.
