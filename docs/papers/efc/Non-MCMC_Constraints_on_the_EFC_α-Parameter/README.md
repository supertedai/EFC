## Overview

Validation note reporting non-MCMC, model-comparison constraints on the Energy-Flow Cosmology (EFC) α-parameter using BAO (DESI Y1, BOSS DR12), multi-epoch growth-rate fσ8, IllustrisTNG cluster statistics, and cosmic chronometer H(z) data. Cross-validation and likelihood-ratio tests consistently prefer EFC over ΛCDM (e.g., Δχ2DESI = −22.01; Δχ2BOSS = −7.77; α = −1.00 ± 0.46 at 2.20σ from fσ8), while concurrent MCMC inference remains degeneracy-limited. Results align within ~0.7σ of sealed blind predictions and are framed as model-comparison metrics, not posteriors.

## Key Result

Non-MCMC model-comparison tests prefer EFC over ΛCDM across BAO and growth probes (Δχ2DESI = −22.01; Δχ2BOSS = −7.77; α = −1.00 ± 0.46 at 2.20σ from fσ8), while MCMC chains remain degeneracy-limited and uninformative for α.
