## Overview

Unbinned maximum-likelihood fit with intrinsic scatter of the EFC screening form ln μ = k ln(1 + g†/gbar) to 174 SPARC galaxies (3264 points). The analysis finds k = 0.415 ± 0.029, g† = (2.51 ± 0.60) × 10^-10 m/s^2, and σ_int ≈ 0.14 dex, and—using an independently obtained aG = 0.094 ± 0.01—infers a cross-scale phase-gain parameter C = 4.4 ± 0.6. This establishes empirical compatibility of EFC with the RAR and provides a quantitative cross-scale consistency check.

## Key Result

EFC’s screening form provides an excellent empirical fit to the SPARC RAR with k = 0.415 ± 0.029, g† = (2.51 ± 0.60) × 10^-10 m/s^2, and σ_int ≈ 0.14 dex, and—combined with aG = 0.094 ± 0.01—implies a cross-scale phase-gain C = 4.4 ± 0.6.
