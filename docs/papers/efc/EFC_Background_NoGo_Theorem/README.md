## Overview

Shows, via three independent parametrisations and a BAO–CMB joint analysis, that any EFC background H(z) modification large enough to improve BAO is decisively ruled out by CMB distance priors. The result is structural (due to DA(z*) integrating through z < 2) and closes Level 3: the EFC background is effectively ΛCDM at current precision, redirecting viable EFC dynamics to the perturbation sector.

## Key Result

Any low-z EFC background H(z) modification large enough to improve BAO (Δχ2_BAO ≈ −14.6) is decisively penalized by CMB distance priors (Δχ2_CMB > +100), yielding Δχ2_total ≈ +98 and closing Level 3 as observationally empty at current precision.
