## Overview

Research note establishing a no-go result for observable background-level modifications in Energy-Flow Cosmology (EFC) under joint Planck 2018 CMB distance priors and DESI DR1 BAO constraints. Three independent parameterisations (linear α·T(a), exponential Geff = G0 exp(aG S), and a regime-aware piecewise H(z)) all show that BAO-improving low‑z changes to H(z) necessarily shift the CMB angular diameter distance DA(z∗) and are ruled out. The result closes Level 3 (background H(z)) at current precision and redirects EFC phenomenology to the perturbation sector (µ, Σ).

## Key Result

Any low-z background modification to H(z) large enough to improve BAO is decisively excluded by CMB distance priors; the EFC background is effectively ΛCDM at current precision and observable effects must reside in the perturbation sector.
