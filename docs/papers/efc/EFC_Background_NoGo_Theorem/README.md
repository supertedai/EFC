## Overview

Shows that any EFC background-level modification to H(z) large enough to improve DESI DR1 BAO fits is decisively ruled out by Planck 2018 CMB distance priors. Using three independent parametrisations (linear α·T(a), exponential Geff = G0 exp(aG S(a)), and regime-aware piecewise H), the paper demonstrates a structural BAO–CMB tradeoff and concludes the EFC background is effectively ΛCDM at current precision, redirecting EFC to the perturbation sector.

## Key Result

Any EFC background H(z) modification large enough to improve BAO (Δχ2_BAO ≲ −5) is decisively excluded by CMB distance priors, yielding Δχ2_total > 0; the EFC background is effectively ΛCDM at current precision.
