## Overview

Analyzes 175 galaxies from the SPARC database using an ultra-phenomenological EFC-fit and a simplified ΛCDM-NFW baseline to test the Energy-Flow Cosmology Regime (EFC-R) framework. Finds a strongly significant regime-dependent validity: EFC-fit succeeds in low-complexity FLOW systems (35%) and systematically fails in high-complexity LATENT systems (15%), with reproducible methods and full data/code release.

## Key Result

EFC-fit exhibits regime-dependent validity across SPARC: 100% success in FLOW (62/175, 35.4%) and systematic failure in LATENT (27/175, 15.4%), with highly significant FLOW–LATENT separation (Mann–Whitney U p < 0.0001).
