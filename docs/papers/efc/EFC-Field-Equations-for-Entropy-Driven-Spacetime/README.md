## Overview

Proposes a covariant field-theoretic framework where a normalized entropy field S(x) and an energy-flow four-vector J^μ source spacetime curvature alongside the metric. The action yields modified Einstein equations that reduce to GR when entropy gradients vanish, with cosmological and galactic-scale phenomenology that can mimic dark matter and alter late-time expansion.

## Key Result

Introduces a covariant entropy–flow sector that sources curvature, recovers GR when ∇S → 0, and yields testable modifications to galactic dynamics, lensing, and the expansion history without invoking particle dark matter or dark energy.
