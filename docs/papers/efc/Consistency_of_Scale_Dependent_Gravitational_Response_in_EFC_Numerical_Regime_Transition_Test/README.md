## Overview

Numerical test showing that a single relativistic EFC action yields suppressed linear growth (μ < 1) on cosmological scales while remaining compatible with enhanced gravity (μ > 1) in the non-linear Newtonian/galactic regime. The scale-dependent stiffness response R(k) ∝ k^-4 drives a smooth transition, recovers GR at high k, reproduces the survival valley (μ ≈ 0.94, η > 1, Σ > 1), and achieves fσ8 consistency with Δχ² = −0.03 versus ΛCDM.

## Key Result

A single EFC action yields μ < 1 in linear cosmology and is compatible with μ > 1 in the non-linear Newtonian regime via a smooth k^-4 stiffness-driven transition, reproducing the survival valley and GR recovery.
