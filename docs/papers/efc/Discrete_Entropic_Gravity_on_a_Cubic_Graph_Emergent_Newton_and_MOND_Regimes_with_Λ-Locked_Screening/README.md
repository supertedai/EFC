## Overview

Constructs a discrete AQUAL-like gravity operator on a cubic graph with entropic flux weighting that reproduces Newtonian (g ∝ r⁻²) and MOND-like (g ∝ r⁻¹) regimes without assuming a continuum metric. A Λ-locked bulk entropic reservoir sets the transition scale (L_Λ ∝ Λ⁻¹ᐟ²), yielding a convergent deep-MOND prefactor C ≈ 2.32 (implying a0,eff ≈ 5.4 a0), broken superposition, an external field effect, and a weak mass-scaling exponent r_trans ∝ M^0.18. A minimal cosmological stability check shows ~0.7–0.8% suppression in σ8/fσ8 via background-only modification.

## Key Result

The cubic-graph entropic operator reproduces Newtonian and MOND-like scalings with a Λ-locked transition and yields a convergent prefactor C ≈ 2.32 (a0,eff ≈ 5.4 a0) and weak mass scaling r_trans ∝ M^0.18, while passing internal kill-tests and showing ~0.7–0.8% growth suppression in a minimal cosmology check.
