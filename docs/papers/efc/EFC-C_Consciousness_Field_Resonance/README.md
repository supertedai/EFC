## Overview

Proposes a field-based ontology of consciousness in which awareness corresponds to a differentiation-dominant resonance regime constrained by regional feedback. Re-analyzing propofol EEG (Chennu et al. 2016), the study finds spectral differentiation (Omega) tracks conscious state with a double dissociation, while global causal integration (kappa) is weak and a pre-registered multiplicative model C = Omega × kappa is falsified. An exploratory parietal product shows a strong effect, and a negative Omega–kappa correlation supports a balance (trade-off) constraint.

## Key Result

Omega strongly tracks conscious state with a double dissociation; global kappa is weak, and the pre-registered product C = Omega × kappa is falsified; exploratory parietal product is strong and the Omega–kappa correlation is negative.
