## Overview

This paper argues that consciousness is best understood as a resonant regime within a universal dynamical field, where systems differ by their capacity to form differentiated, self-referential dynamical structures. Empirical analysis of EEG under propofol sedation shows spectral differentiation (Omega) tracks conscious state with a double dissociation.

**Key Finding:** The pre-registered multiplicative model C = Omega x kappa is falsified (F1). A differentiation-dominant, regionally constrained resonance model is supported.

---

## Framework: Consciousness-Ego-Mirror (CEM)

### Core Measures

- **Omega (Spectral Differentiation):** Spectral entropy measuring internal differentiation/structured complexity. Cohen's d = 1.50.
- **kappa (Causal Integration):** Transfer entropy measuring regional causal closure. Cohen's d = 0.42.
- **C = Omega x kappa:** Product measure -- FALSIFIED (F1).

### Empirical Pillars

1. Differentiation is primary (Omega d=1.50, double dissociation)
2. Global integration not detected; regional integration candidate (kappa d=0.42, Parietal C d=2.10)
3. Balance, not maximisation (negative Omega-kappa correlation r=-0.27)
