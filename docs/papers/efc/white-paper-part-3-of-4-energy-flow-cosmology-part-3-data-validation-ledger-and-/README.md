## Overview

Presents a structured validation ledger for Energy-Flow Cosmology (102 registered tests), two sealed blind predictions with cryptographic provenance, and a pre-registered falsification protocol for Stage-IV surveys. Reports a persistent but non-detection growth-sector signal (αL2 = −1.00 ± 0.46, ΔAIC = −2.91) and defines sharp kill criteria that would compel abandoning EFC.
