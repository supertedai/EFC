## Overview

This Stage-1 empirical test falsifies an EFC-modified Toomre-Q bar-instability criterion on SPARC galaxies (AUC 0.22–0.31 within the physically allowed ζ range), closing the bar-prediction track. In the same data, the minimum EFC-Q (Πmin) within the disk window emerges as a robust disk-state proxy, correlating strongly with stellar surface density (negative) and gas fraction (positive), with replication on an independent xGASS sample.

## Key Result

EFC-BIC fails as a bar predictor (AUC 0.22–0.31; anti-correlated with SB/SA truth within physical ζ), but Πmin is a strong, reproducible disk-state proxy anti-correlated with log Σ and positively correlated with fgas.
