## Overview

This paper empirically tests an EFC-modified Toomre-like stability parameter ΠEFC, which augments the epicyclic frequency with an entropy-flow term, as a predictor of bar morphology in disk galaxies. The bar-onset criterion is falsified (AUC 0.22–0.31, anti-correlated with truth), but the minimum Π within the disk window strongly correlates with independent disk-state observables (negative with stellar surface density, positive with gas fraction) across SPARC and xGASS samples. Πmin is thus registered as a Stage-1 candidate disk-evolutionary-state proxy on the joint (Σ, fgas) manifold.

## Key Result

EFC-BIC fails as a bar predictor (AUC 0.22 local v0.1; 0.31 resonance-aware v0.2; anti-correlated rankings), but Πmin robustly correlates with disk state (SPARC N=112: ρ[Πmin, log Σdisk] = −0.71, ρ[Πmin, fgas] = +0.65; xGASS N=98: ρ[Πproxy, log Σ∗] = −0.49, ρ[Πproxy, fgas] = +0.67), supporting Π as a Stage-1 disk-evolution parameter.
