## Overview

This Stage-1 empirical test falsifies an EFC-modified Toomre-Q bar-instability criterion on SPARC galaxies (AUC 0.22–0.31; anti-correlated with bar truth within the physically allowed ζ range). In the same data, the minimum ΠEFC within the disk window shows strong, replicable correlations with disk structural state (anti-correlated with stellar surface density and positively correlated with gas fraction) across SPARC and xGASS, motivating Πmin as a candidate disk-state parameter on the joint (Σ, fgas) manifold.

## Key Result

The EFC bar-instability criterion fails as a bar predictor (AUC 0.22–0.31; anti-correlated with bar truth within physical ζ), but Πmin robustly tracks disk structural state (ρ[Πmin, log Σ] ≈ −0.71; ρ[Πmin, fgas] ≈ +0.65 on SPARC; replicated on xGASS).
