# EFC — How Energy Flow Sustains Spacetime

**DOI:** [10.6084/m9.figshare.28098371](https://doi.org/10.6084/m9.figshare.28098371)

This directory contains the paper explaining how continuous energy flow
maintains the structural, geometric, and dynamical properties of spacetime
within the Energy-Flow Cosmology framework. The paper outlines how
entropy gradients, resistance fields, and distributed flows provide the
underlying support for spacetime stability and large-scale structure.
