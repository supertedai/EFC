# EFC — Energy Flow as the Fundamental Dynamic of the Universe

**DOI:** [10.6084/m9.figshare.28113542](https://doi.org/10.6084/m9.figshare.28113542)

This directory contains the paper presenting the core claim of the
Energy-Flow framework: that energy flow (Ef), not mass or spacetime
curvature, is the primary dynamic shaping structure, motion, and the
observable universe.
