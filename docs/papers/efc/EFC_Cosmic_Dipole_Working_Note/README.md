## Overview

Working note that proposes a natural EFC mechanism for the excess galaxy number-count dipole (2–3× kinematic). In EFC, large-scale isotropy is a regime condition; a residual super-Hubble entropy gradient ∇S modulates the effective coupling G_eff(S) and thus structure growth, yielding a dipole aligned with the CMB but with amplified amplitude. The note derives the leading-order dipole, estimates the required ~2% entropy gradient, and states falsifiable predictions and open gaps.

## Key Result

EFC naturally yields an intrinsic number-count dipole via a super-Hubble entropy gradient modulating G_eff(S), with the observed excess explained by an O(2%) gradient across the survey volume.
