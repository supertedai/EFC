## Abstract

SHA-256 sealed predictions for Euclid DR1 (October 2026) generated by a custom
`efc_logistic` gravity model implemented in the hi_class Boltzmann solver. The
EFC logistic entropy field S(a) = 1/(1+exp(-(ln a - ln a\_t)/Delta)) drives
Horndeski alpha-functions (alpha\_M = M0\*S(a), alpha\_B = B0\*dS/dlna) with
analytical delta\_M2 computation to avoid ODE stiffness. A 36-point parameter
scan establishes the allowed region and Planck ISW constrains M0 < 0.1.

**Benchmark:** B0 = 0.02, M0 = 0.06, a\_t = 0.3, Delta = 0.3

**Coherence signature:** sigma8 UP, P(k) UP, lensing DOWN, ISW UP, E\_G DOWN.
Opposite to neutrino mass effects. Cannot be produced by galaxy bias, IA, or photo-z systematics.

**SHA-256:** `dbc737979d8a773f56c620759ddded38139157fd9a2dbb321a8ffdb6e68135d2`

## Constraints

- Stability boundary: M0 >= 3\*B0 (braiding requires Planck mass running)
- Planck ISW: M0 < ~0.1 (Cl^TT at low ell)
- Allowed parameter space: B0 in [0, 0.03], M0 in [0.01, 0.10]

## Quick Start

```python
from src.efc_logistic_demo import EFCLogistic

model = EFCLogistic(B0=0.02, M0=0.06, a_t=0.3, Delta=0.3)

# Entropy field at z=0
print(f"S(a=1) = {model.S(1.0):.4f}")       # 0.9822
print(f"alpha_M(a=1) = {model.alpha_M(1.0):.4f}")  # 0.0589
print(f"alpha_B(a=1) = {model.alpha_B(1.0):.4f}")  # 0.0012

# M*2 (Planck mass squared) at z=0
print(f"M*2(a=1) = {model.M2(1.0):.4f}")    # analytical
```

## Relation to EFC Framework

This is the first Boltzmann-level calibration of EFC predictions. Previous
estimates (5-7% signal from paper-based mu/eta/Sigma) are replaced by
hi_class-computed Cl and P(k) giving 1-3% signals. The pipeline is at
`pipelines/efc/euclid_dr1/` with 6 sanity checks and RCMP compliance matrix.
