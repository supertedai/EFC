## Overview

Pre-registered, frozen predictions for Energy-Flow Cosmology (EFC) to be tested against Euclid DR1, computed via full Boltzmann integration in hi_class with a custom efc_logistic Horndeski implementation. At the benchmark (B0=0.02, M0=0.06), five linear observables exhibit a coherent growth–lensing pattern (e.g., σ8 up, C_ell^{ϕϕ} down) that is hashed for integrity and claimed to be distinct from known systematics or massive neutrino effects.

## Key Result

At (B0, M0) = (0.02, 0.06), EFC predicts a coherent five-observable signature decoupling growth and lensing (e.g., σ8 +1.21%, C_ell^{ϕϕ}(ℓ=66) −6.01%), sealed by a SHA-256 hash for Euclid DR1 falsification.
