## Overview

This note presents the perturbation-sector prediction of Energy-Flow Cosmology (EFC) for weak-lensing amplitude as a function of redshift, summarized by an effective ratio eff(z) relative to a CDM baseline set to unity. EFC predicts a single redshift crossover at z ≃ 0.42 separating enhanced (eff > 1) from suppressed (eff < 1) lensing, with percent-level deviations bounded at approximately ±2% over 0.2 ≲ z ≲ 1.4. The result is posed as a sealed, falsifiable target for upcoming weak-lensing tomography.

## Key Result

EFC predicts a weak-lensing efficiency ratio eff(z) that crosses unity at z ≈ 0.42 with deviations confined to about ±2% over 0.2 ≲ z ≲ 1.4, implying enhanced lensing below the crossover and suppressed lensing above it relative to CDM.
