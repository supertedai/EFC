## Overview

Introduces EFC-C, a thermodynamic framework that models the brain as an open system governed by entropy-gradient dynamics. It defines a scalar neural entropy production rate and a gradient tensor over the connectome, yielding three falsifiable predictions on hub-to-periphery entropy topology, disorder-specific gradient signatures, and a cognitive threshold. The paper shows qualitative consistency with published EEG/fMRI findings and outlines a prospective validation protocol.

## Key Result

EFC-C predicts a centrifugal hub-to-periphery entropy topology, disorder-specific gradient signatures, and a cognitive entropy-production threshold, and shows qualitative consistency with published EEG/fMRI literature.
