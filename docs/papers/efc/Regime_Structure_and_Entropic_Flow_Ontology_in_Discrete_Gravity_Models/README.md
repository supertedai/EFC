## Overview

Formalizes a regime-based ontology for discrete entropic gravity on graphs, showing how Newtonian (UV), MOND-like (IR), and cosmological (Yukawa-screened) behaviors arise from dominance switching between gradient, bulk, and source sectors of a single functional. Clarifies the role of the cosmological constant Λ as a bulk entropic capacity parameter that sets both the local MOND transition scale and the global screening length, all without assuming a fundamental spacetime metric.

## Key Result

A single graph-defined entropic functional yields three exhaustive regimes—Newtonian, MOND-like, and Yukawa-screened—via dominance switching between gradient and bulk sectors, with Λ setting both a0 and the Gpc-scale screening length.
