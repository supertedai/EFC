## Overview

Shows that, on an FRW background in the quasi-static sub-horizon regime, the linear perturbation equations of Energy-Flow Cosmology (EFC) admit an effective mapping to the Bellini–Sawicki Horndeski α-function basis. Identifies αT = 0, derives αM ∝ S(a) and αB ∝ dS/d ln a from the EFC dynamics, and isolates a scale-dependent stiffness response R(k, z) with no direct BS analogue that suppresses µ(k) on cosmological scales. This closes the formal gap between the EFC action and Euclid’s EFT/hi_class pipeline for linear perturbations.

## Key Result

In the FRW quasi-static sub-horizon limit, EFC linear perturbations map to an effective Bellini–Sawicki representation with αT=0, αM ∝ S(a), and αB ∝ dS/d ln a, while a distinct stiffness response R(k, z) produces scale-dependent µ suppression beyond standard Horndeski.
