## Overview

Complete documentation of the Entropy-Bounded Empiricism (EBE) framework applied to the SPARC175 galaxy rotation curves. The paper reports regime-dependent model validity with 100% EFC success in the FLOW regime (62/62) and strong nonparametric evidence (Mann-Whitney p < 0.0001, Cliff's δ = 0.371), while a CMB null test (p = 0.251) shows no regime structure, supporting the framework's specificity to non-equilibrium systems.

## Key Result

EFC achieves 100% success in the FLOW regime (62/62) with strong regime-dependent structure (p < 0.0001, Cliff's δ = 0.371), while the CMB shows no such structure (p = 0.251).
