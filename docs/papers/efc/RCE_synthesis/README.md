## Overview

Introduces Regime-Closure Epistemology (RCE) as an operational principle for validating coupled multi-scale systems. The paper specifies five joint conditions—regime locality, variety closure, modelling closure, frozen-parameter governance, and external arbitration via sealed predictions—arguing that validation is sound if and only if these hold. It consolidates EFC machinery (EBE, RCMP, L0–L3 architecture, sealed predictions, and a live falsification ledger) and deposits pre-registered cross-domain predictions.

## Key Result

States and operationalizes RCE: validation in coupled multi-scale systems is valid iff five specified regime-closure conditions are jointly satisfied, with sealed, pre-registered cross-domain predictions deposited for external arbitration.
