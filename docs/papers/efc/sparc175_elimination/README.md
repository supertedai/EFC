## Overview

This paper performs a systematic elimination study of baryon-based rotation-curve models on the SPARC 175 sample. It shows that all purely local multiplicative models with only global parameters fail in low-acceleration (FLOW) galaxies, while a minimal hybrid model with a single galaxy-specific amplitude matches NFW halo fit performance with half the per-galaxy parameters. The study finds the added amplitude is a stable, intrinsic galaxy property that cannot be predicted from standard baryonic observables.

## Key Result

All purely local multiplicative models with only global parameters are falsified on SPARC 175 (FLOW win ≈ 27%), while a one-parameter-per-galaxy hybrid matches NFW performance (FLOW win 72.6%, median χ2/dof 2.71 vs 2.64).
