## Overview

This pre-registration seals quantitative, falsifiable predictions of the Energy-Flow Cosmology (EFC) model for Rubin Observatory LSST Data Preview 2 (DP2) cosmic shear. It forecasts an ~8–10% large-scale lensing enhancement and S8 = 0.847 ± 0.015 driven by a gravitational slip η ≈ 1.10, and specifies explicit falsification thresholds against the forthcoming DP2 measurements.

## Key Result

Sealed EFC predictions for Rubin LSST DP2: S8 = 0.847 ± 0.015 and ~8% enhancement of ξ+(θ) at 20′–300′ driven by η ≈ 1.10, with explicit >2σ falsification thresholds.
