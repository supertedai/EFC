## Overview

Introduces the Regime-Consistent Measurement Principle (RCMP), a methodology that requires interpreting observables via variables most directly coupled to the physical driver within the operative regime, with explicit cross-regime transformation and uncertainty propagation. The paper formalizes five core principles (driver proximity, regime tagging, proxy accounting, coordinate humility, and cross-validation) and demonstrates the framework on galaxy rotation curves, separating intra-galaxy from inter-galaxy effects and resolving an apparent low-acceleration scatter discrepancy in the SPARC dataset.

## Key Result

Applying RCMP to SPARC rotation curves shows dwarfs have 1.27× higher per-point scatter than spirals in the low-g regime (p = 0.02) while per-galaxy median responses are statistically indistinguishable (p = 0.47), separating intra-galaxy variability from inter-galaxy physics.
