# DOI Ledger Consistency Audit — 2026-04-29

## Summary

Repo-internal DOI cross-validation across three canonical sources found
**37 inconsistencies**, all closeable by adding entries from each paper's
own `index.json`. The migration script
[`scripts/maintenance/apply_audit_patch_2026_04_29.py`](
../../scripts/maintenance/apply_audit_patch_2026_04_29.py) applies the
fix idempotently.

## Sources used

| Source | Role | Pre-audit |
|---|---|---|
| `figshare/doi-map.json` | Curated DOI → path → title mapping | 156 DOIs |
| `docs/papers/efc/efc_index.json` | Master paper index | 131 unique DOIs (134 entries) |
| `docs/validation-ledger/data/evidence-register.json` | Public ledger | 89 DOIs |
| `docs/papers/efc/<dir>/index.json` × 36 | Per-paper canonical metadata | — |

DOI was treated as the priority source, per project policy. External DOI APIs
(Figshare, DataCite, Crossref, ORCID) were not reachable from the audit
sandbox; cross-validation used only repo-internal canonical files. The 36
papers touched by the patch all have valid `index.json` files in
`docs/papers/efc/<dir>/`, and each declares its own DOI internally — the
patch propagates those declarations into the cross-reference indexes.

## What the patch does

1. **Adds 2 new DOIs to `figshare/doi-map.json`** — papers exist in repo
   but were missing from the DOI map:
   - `32099389` — *Homo Fluxus: A Thermodynamic Framework for Consciousness…*
     → `docs/papers/efc/Homo Fluxus A Thermodynamic Framework`
   - `32113399` — *A Three-Window Decomposition of Cosmological Redshift in EFC*
     → `docs/papers/efc/efc_redshift_decomposition`

2. **Fills 10 empty `title` fields in `figshare/doi-map.json`** — sourced
   from each paper's own `index.json`:
   `31127380, 31144030, 31190233, 31222696, 31222900, 31223668, 31224466,
   31348414, 31348417, 31562200`.

3. **Adds 26 missing entries to `docs/papers/efc/efc_index.json`** — each
   entry's `id`/`path`/`type`/`doi` sourced from the paper's `index.json`:
   - 4× EFC White Paper Part 1–4 (31970886, 31970898, 31970904, 31970907)
   - EFC Background No-Go Theorem (31985163)
   - 9× sealed predictions / observational pipelines (31985313, 31990053,
     31990194, 31990212, 32010399, 32013156, 32013738, 32023788, 32037990,
     32045592)
   - 6× methodology / RCMP / compound papers (32011407, 32019723, 32080059,
     32080080, 32080083, 32113399)
   - 3× empirical tests (32029704, 32084670, 32101111)
   - 2× theory papers (31969983, 32099389)
   - Bumps version `1.10 → 1.11`, `n_papers 134 → 159`

## Out of scope

- **`28102772`** — orphan in doi-map, `path: null`. Needs human judgment.
- **`evidence-register.json`** — auto-generated by `efc_sync_dois.py`
  from `tests.json` paper-directory matches. Not touched.
- **5 DOIs claimed on the Figshare author page** that are not yet in the
  repo at all. Cannot be identified from sandbox without external API
  access; owner can post the list and a follow-up PR can register them.
- **Neo4j / Atlas / Qdrant / GNN consistency** — out of audit scope (no
  service access from sandbox). KT1–KT5 status in `grav.json` is
  internally consistent (KT1/KT2 PASSED, KT3 MARGINAL, KT4/KT5 defined
  but not yet run); any contradiction with Neo4j must be reconciled
  there.
- **Title drift on `28098326`** — `evidence-register` and `doi-map`
  disagree. Kept as-is; needs human pick of canonical title.
