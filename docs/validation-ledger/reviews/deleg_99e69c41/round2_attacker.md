# Round-2 adversarial attack

## 1. Sharpest overall attack

The manuscript is careful about saying that it has not run a fit, but that honesty does not make its central physical object executable: it inventories several mutually non-equivalent formulas, assigns them status labels, and then describes MOND-like and LCDM-like behavior as regimes of one framework without freezing the typed maps, units, invariant parameters, regime boundaries, or nuisance pipelines that would make those statements testable. The document can therefore retreat to provenance bookkeeping whenever a physical claim is challenged, while still borrowing the rhetorical force of “derived,” “upgrade,” “special case,” “emergent,” and “single underlying framework.” The source artifacts make this more serious, not less: package 31942821's metadata/README describe a saturating $\Gamma_0\rho/(\rho+\rho_{\rm crit})$, while its source header and implementation expose Scenario B, $\Gamma\propto\rho^{3/2}/(\rho+\rho_{\rm crit})$, evaluated through a dimensionless `rho_ratio`; the SPARC proposal itself says that M/L, distance, inclination, and gas treatment still require decisions; and the siren formula is invariant under field rescaling, so freezing $\alpha$, $\phi_0$, and a symbol called $\phi(z)$ is not the same as freezing the predicted history. The result is a defensible inventory of unresolved work, but not yet a falsifiable model-family reconciliation.

## 2. Per-claim attacks

### C1 — Three distinct realized $\Gamma(\rho)$ forms

**Attack.** The displayed expressions are present in the frozen text, but “realized” silently upgrades textual presence to a coherent, executable implementation. The cited source package is not a single stable witness to the asserted object: its metadata and README call the main result the saturating $\Gamma_0\rho/(\rho+\rho_{\rm crit})$ form, whereas `src/entropy_production.py` advertises Scenario B, $\Gamma(\rho)\propto\rho^{3/2}/(\rho+\rho_{\rm crit})$, and implements `gamma_total(rho_ratio)` on a dimensionless input normalized to $\Gamma_0$ at $\rho=\rho_{\rm crit}$. The manuscript lists both as if the difference were merely a model-family branch, but does not say which artifact is normative when PDF/metadata/source disagree.

The three expressions are also not yet three comparable physical responses. $\Gamma_A$ and $\Gamma_C$ are dimensionless under the stated density convention; $\Gamma_B$ is not. A formula can be “realized” as a code path while still lacking a typed physical interpretation. Nor is it shown that the three shapes are invariant under the permitted change from $\rho$ to $u=\rho/\rho_{\rm crit}$ and a branch-specific normalization. At present the strongest defensible wording is “three expressions or code-level ansätze occur in the corpus,” not “three realized forms of one effective response.”

**Residual closure required.** Pin the exact package versions and normative layer; show that each form appears in the executable source, has declared units and parameter semantics, and maps to the same kind of observable. If the dimensionless `rho_ratio` implementation is the intended repair, state the conversion explicitly rather than treating it as evidence that the dimensionful published expression was already closed. (Round-1: F-fals-1, F-cart-1, F-form-1, F-prov-1.)

### C2 — No maturation chain; a shape bifurcation with one B $\to$ B$^+$ relation

**Attack.** “No demonstrated maturation chain” is a defensible statement about the current ledger; “shape bifurcation” is an author-selected historical taxonomy. The manuscript supplies no criterion that distinguishes a genuine bifurcation from an unresolved contradiction inside one package, a reparameterization, or a set of independently proposed ansätze. The A/B divergence in package 31942821 can be described as a conflict in source fields without implying a bifurcation in model space. Calling B $\to$ B$^+$ the one relation also assumes that the corpus graph is complete and that other relations do not exist outside the selected table.

The absence of an executed discriminator cannot establish the genealogy. A future held-out comparison could select a branch, but it would not show that the selected branch is historically a maturation or that the other branch was a predecessor. Conversely, a null comparison would leave the relation unresolved. Thus C2 is mostly a self-description of the ledger, not a falsifiable physical proposition. The phrase “shape bifurcation” should be demoted to a provisional graph label and kept separate from any claim about distinct mechanisms or development.

**Residual closure required.** Define the equivalence relation under which two branches count as the same model, freeze the allowed normalizations and reparameterizations, and distinguish source history from predictive selection. Until then the manuscript should say only that no maturation or supersession has been demonstrated.

### C3 — $\Gamma_B$ has residual dimension $\sqrt{[\rho]}$

**Attack.** The algebraic diagnosis is correct if $\rho$ and $\rho_{\rm crit}$ are dimensional densities and if the displayed $\Gamma_B=\rho^{3/2}/(\rho+\rho_{\rm crit})$ has no omitted factor: $[\Gamma_B]=[\rho]^{1/2}$. The claim becomes vulnerable when it treats that diagnosis as a settled source-package fact while leaving the source's implicit normalization unexamined. The source module supplies `Gamma_0`, accepts a dimensionless `rho_ratio`, and returns `Gamma_0*rho_ratio**1.5/(1+rho_ratio)`. That is an implementation-level reference-density normalization in disguise. It may repair the units of the code-level branch, but the package never writes the required physical factor explicitly (for example $\rho_*^{-1/2}$), never assigns units to $\Gamma_0$, and never gives the map from the normalized code quantity back to the dimensionful $\mathrm dS/\mathrm d\rho$ or to the $\Box\phi$ source.

This creates a fork that the manuscript does not resolve. If the source-level `rho_ratio` convention is authoritative, the categorical statement that no source-supplied reference scale exists is too strong; the real defect is that the implicit scale and $\Gamma_0$ are untyped and not connected to the published equation. If the published expression is authoritative, the residual unit leak remains open exactly as stated. The source also defines $\beta=4\pi G_N/3$ in the implementation while its docstring says $\beta=4\pi G_N r_*/3$, so the dimensional problem is not confined to a cosmetic prefactor. A freely chosen reference density can always make a formula dimensionless; that does not establish the physical normalization, entropy units, or cross-package identity.

**Residual closure required.** Freeze one canonical equation, one density variable, and one normalization. Write the explicit prefactor/reference density, its units and origin, the units of $S$, $\Gamma_0$, and $\Box\phi$, and the typed maps among $\mathrm dS/\mathrm d\rho$, the relativistic source, the grid-action quantity, and any rates. Then test that the same conversion is used in all branches. Until that is done, C3 is not merely an open observational issue: it is an unresolved object-identity and unit leak. (Round-1: F-fals-3, F-cart-3, F-form-3, F-prov-3; source audit of 31942821.)

### C4 — B $\to$ B$^+$ is a declared companion upgrade; supersession is not established

**Attack.** As a ledger label, “declared companion upgrade” is traceable. As language, “upgrade” carries a directional quality claim that the surrounding disclaimers do not fully neutralize. The source code header itself says the companion “upgrades to Scenario B+,” but no common normalized observable, derivation, predictive score, or predeclared criterion defines what counts as an upgrade. If B and B$^+$ are not yet typed as the same physical quantity, it is impossible to know whether B$^+$ is a replacement, a rescaling, a different branch, or a different model.

“Supersession not established” blocks one strong conclusion but does not remove the hidden prior induced by the word upgrade. A reader can reasonably infer that B$^+$ is the preferred or corrected form even though the paper says no such selection has occurred. This is particularly dangerous because the source package's own key-result fields already disagree about saturation and exponent. The honest status is “companion candidate named by the source,” unless the author is prepared to defend upgrade as a purely administrative relation with no implied improvement.

**Residual closure required.** Replace “upgrade” by a neutral relation until a common observable and selection rule are fixed, or explicitly define the relation as metadata only. A held-out comparison can establish empirical preference; it cannot by itself prove historical supersession.

### C5 — Two separate model-family axes, both open

**Attack.** The manuscript demonstrates two useful bookkeeping axes, not a factorization of the physical theory. The E-axis uses $g$ and an exponent; the $\Gamma$-axis uses $\rho$ and a response shape. No typed map shows that the choices are separable, and both branches share likely scales and couplings ($a_0$, $C$, $\rho_{\rm crit}$, field normalizations, and source mappings). The text itself concedes that physical independence is not demonstrated, which means “separate axes” cannot be read as independent selections.

The missing Gamma-shape discriminator is not a harmless omission. It leaves an entire model choice open while the proposed SPARC test addresses only the E-exponent. After seeing a residual, the analyst could select $\Gamma_A$, $\Gamma_B$, or $\Gamma_C$, alter the normalization, and then report the E-axis result as if the model family had been tested. The proposed test axes and model-family axes are verbally separated, but the likelihood that will be used in practice still has to include their cross-product and shared nuisances.

**Residual closure required.** Freeze a joint model grid over exponent and Gamma shape, including shared parameters and priors, and specify a common observable and held-out score before seeing residuals. Until then C5 is a descriptive taxonomy with a post-hoc branch-selection loophole, not an executable two-axis validation design. (Round-1: F-fals-5, F-form-4, F-para-4, F-cart-5.)

### C6 — The two square roots are distinct roles and must not be conflated

**Attack.** The syntactic distinction is real: one square root is written in an energy/acceleration relation and another in a density response. The manuscript has not shown physical independence, however, and the cited implementation makes the coupling problem worse. Package 31942821 describes $x(\rho)=\sqrt{\beta\rho/a_0}$ while also defining $g(\rho)=\beta\rho$ and calling $x=g/a_0$; the source code uses the square-root density variable directly. The same $\rho$ therefore enters the BE argument and the Gamma branch, and the package's own typed relation between $g$ and $\rho$ is internally inconsistent.

Saying “do not conflate them” can therefore become a shield against the harder question: are they independent physical choices, mechanically linked by the same derivation, or merely non-identifiable after a field/scale redefinition? A shared exponent of $1/2$ proves none of these. If a joint action forces one choice, the two-axis story is false; if the data identify only a product of the exponent and the density scale, the axes are not separately testable even if the notation is different.

**Residual closure required.** Publish the typed transformation rules from $g$ to $\rho$, $\Gamma$, the BE argument, and the observable, resolve the contradictory $x(\rho)$ definition, and fit crossed combinations with shared nuisance parameters. The claim should remain a representational distinction, not an assertion of independent physical degrees of freedom.

### C7 — KC1 is an explicit conditional falsification criterion

**Attack.** KC1 is logically valid only in the weak sense that a stipulated antecedent implies a stipulated consequence. It is not yet a reproducible kill criterion. “Robust,” “bias-controlled,” “preferred,” “diverse systems,” “significantly,” and “the $\sqrt g$ form” are not operational predicates. The statistic, data release, sample and radial cuts, acceleration range, per-galaxy versus pooled aggregation, covariance, outlier rule, nuisance priors, sigma conversion, and threshold implementation are absent. A square root of a dimensionful $g$ is not even a complete competing screening function without a reference scale or dimensionful coefficient. The relevant $a_0$ is still one of several unfrozen values.

There is also a scope overreach in the consequent. A result that rejects the particular $E\propto\sqrt g$ screening mapping could falsify that theorem or implementation; it does not automatically falsify all EFC constructions, the Gamma axis, the relativistic action, or the broad energy-flow ontology. The manuscript correctly says the criterion is conditional, but the current wording still lets a familiar MOND/RAR comparison act as an untyped answer key for a much larger framework.

**Residual closure required.** Freeze the exact linear and square-root functions, $a_0$, reference scales, raw data, measurement model, nuisance path, likelihood, test statistic, aggregation, regime domain, and decision rule before data access. State whether the target is one theorem, one package, or the whole framework. Until then “$\ge5\sigma$” is a nominal label rather than an executable falsifier. (Round-1: F-fals-7, F-mp-1, F-form-6, F-para-6.)

### C8 — KC1's $\ge5\sigma$ provenance gap remains open

**Attack.** C8 is one of the manuscript's more honest claims, but it is only a diagnosis of missing metadata. Null $\Delta\chi^2$ and significance fields plus “no new fit performed” establish that this reconciliation did not reproduce the statistic; they do not establish that the earlier $\ge5\sigma$ statement is false, nor do they identify whether it came from an external fit, an earlier repository commit, or an unrecorded analysis. The manuscript continues to print the threshold in the KC1 narrative, so a reader can still mistake an inherited condition for an empirical result.

The acknowledged repository/Figshare wording divergence makes the gap material rather than clerical. A DOI citation cannot simultaneously certify the corrected conditional text and the older published artifact without a version-level readback. The open status is therefore appropriate but not sufficient: the critical claim is still carried in the document without a resolvable evidence chain.

**Residual closure required.** Locate the exact source version, data, code, configuration, cuts, statistic, and output, or quarantine the sigma statement as unverified external text. A null metadata field must never be presented as a reproduced null or as evidence for either model.

### C9 — SPARC/RAR proposal and the unfrozen $a_0$

**Attack.** Freezing $a_0$ is necessary, but it is plainly not the only unfrozen item. The actual Axis-1 preregistration says that the stellar mass-to-light ratio requires an independent freeze or a declared prior, and that distance, inclination, and gas-mass treatment still require decisions. It explicitly warns that an unfrozen M/L turns a retrodiction into a fit. Those are not side details: they determine $g_{\rm bar}$, $g_{\rm obs}$, their covariance, and the apparent location and slope of the RAR.

The candidate scale itself is not cleanly independent. $1.2\times10^{-10}\,\mathrm{m\,s^{-2}}$ is identified as the MOND/SPARC value in the source code and index; $6.5\times10^{-10}$ is not canonical in the paper index; and $a_{0,\rm eff}=C^2a_0$ inherits the unresolved $C$ provenance and normalization. Choosing among these after looking at the RAR is parameter shopping even if the final chosen number is held fixed during the fit. An imported scale can be a valid external input, but it cannot simultaneously be advertised as an EFC prediction without an independent derivation.

There is a deeper missing mediator. The manuscript moves from an exponent in an energy-screening relation to a RAR likelihood without supplying the complete field solution, baryonic source model, boundary conditions, and map to rotation velocities. A fixed $a_0$ plus a fixed symbolic curve is not an EFC prediction if the forward operator is still open. The discriminator becomes executable only after freezing, at minimum, the raw SPARC release, galaxy/radial cuts, distance and inclination data, gas conversion, stellar M/L prior, beam and deprojection treatment, covariance, nuisance optimization, model comparison statistic, holdout rule, and the EFC-to-$g_{\rm obs},g_{\rm bar}$ forward map.

**Residual closure required.** Rewrite C9 as “proposed and blocked by multiple author decisions,” not “blocked by $a_0$.” Run the two exponent forms and relevant alternatives with identical nuisance treatment on a predeclared holdout, and report the result as a conditional proxy test rather than a unique EFC validation. (Round-1: F-fals-9, F-mp-3 through F-mp-5, F-para-8; the Axis-1 preregistration §5 and §11.)

### C10 — Siren discriminator and the unfrozen coupling

**Attack.** The manuscript's condition is both too strong in one way and too weak in another. It is too strong to say that $\alpha$, $\phi_0$, and $\phi(z)$ must be individually frozen: under $F(\phi)=1+\alpha\phi$, the transformation $\phi\mapsto\lambda\phi$, $\alpha\mapsto\alpha/\lambda$ leaves the observable unchanged. The identifiable quantity is the invariant history
\[
R(z)=\frac{F(\phi_0)}{F(\phi(z))}
=\frac{1+\alpha\phi_0}{1+\alpha\phi(z)},
\]
with $F(\phi_0)>0$ and $F(\phi(z))>0$ on the tested redshift range. Freezing symbols separately can freeze a convention while leaving $R(z)$ arbitrary.

It is too weak to imply that freezing those quantities, or even the invariant ratio, would make a non-unit siren ratio uniquely EFC-specific. A free or incompletely parameterized $\phi(z)$ is an infinite-dimensional tuning function. A fixed $R(z)$ would give a determinate EFC curve, but the same curve can arise from other modified-gravity friction sectors or from calibration, waveform/inclination, host/redshift, lensing, peculiar-velocity, selection, or cosmological-background systematics. The source package's illustrative defaults (`alpha=0.01`, `phi_bar=0.05`, and example endpoint values) are pedagogical code values, not a sealed prediction or a preregistered history.

**Residual closure required.** Freeze the invariant $R(z)$ or an explicitly parameterized $F(\phi(z))/F(\phi_0)$ trajectory, its initial conditions and domain, the background and quasi-static/sub-horizon validity range, and the field-independent nuisance model. Pre-register a joint likelihood against equality, alternative friction models, and channel systematics. The manuscript's current “EFC-specific once $\alpha,\phi_0,\phi(z)$ are frozen” sentence should be replaced by “potentially EFC-specific only after the invariant propagation history and competing explanations are frozen.” (Round-1: F-form-9, F-fals-10, F-mp-6/F-mp-7, F-para-9/F-para-10.)

### C11 — No new fit, no axis selection, no independent validation

**Attack.** This is a narrow scope assertion, not evidence about the corpus. The manuscript can truthfully say that the reconciliation contains no new fit while still importing inherited numerical outputs, source-package “passes,” a lattice convergence value, and earlier model selections. It can say no independent validation is claimed while the reader sees a large internal review apparatus and multiple package-level kill-test results. Agreement among the round-1 roles is explicitly same-model reading consistency, not independence; it cannot certify the negative claim.

The absence of a fit in the frozen prose also does not prove the absence of an unreported execution in the repository or an external validation behind a cited number. “No axis selection” must be scoped to this document and named axes; the source packages themselves do label Scenario B, B$^+$, and internal pass states. Without a command manifest, data hashes, output hashes, and a clean-tree audit, C11 is a disclaimer that limits interpretation but does not close provenance.

**Residual closure required.** Keep the scope wording, but attach it to a reproducible execution manifest and explicitly quarantine every inherited numerical result. Do not let “not claimed here” be read as “not performed anywhere” or “not already selected in the source corpus.”

### C12 — Byte-for-byte reproducibility is open; the current build is warning-free

**Attack.** The first half is a candid non-achievement claim; the second half is unsupported by the frozen evidence chain. The round-1 reproducer found that the build script discards the two TeX passes' output, does not persist a build log or `.build.sha256`, and does not parse for Overfull, Underfull, or float-placement warnings. A PDF hash proves that an artifact exists, not that the run was warning-free. The mutable `texlive:latest-minimal` recipe and mutable `efc-tex:2026` tag further prevent an exact environment claim.

The manuscript also risks conflating three different properties: byte identity, semantic reproducibility of the PDF, and reproducibility of the scientific source-to-observable pipeline. A warning-free LaTeX run establishes none of the latter. The wording correctly says that byte identity has not been achieved, but its warning-free subclaim remains an unlogged author report and should not be placed alongside a reproducibility statement without evidence.

**Residual closure required.** Pin the image by digest and the source tree by manifest hash, retain raw logs, run the exact build twice, compare complete bytes and metadata, and separately test semantic/source-data reproducibility. Until then C12 is only half verified. (Round-1: F-rep-2 through F-rep-5, F-prov-12, F-fals-12.)

### C13 — MOND-like and LCDM-like behavior as candidate effective regimes of one framework

**Attack.** This is the most serious conceptual vulnerability. The manuscript is correct that the regime reading is labelled a hypothesis, but a hypothesis is not made scientific merely by calling it “candidate.” As written, “global linear/screened L0/L1 LCDM-like” and “local low-acceleration IR MOND-like” are imported phenomenological labels, not pre-data regimes with numerical boundaries. The manuscript provides no dimensionless control vector, transition surface, order of limits, typed parent-to-observable map, or cross-regime prediction. The cited package identifiers show that the corpus contains papers with those labels; they do not show that one action actually generates both limits.

The gap is structurally unfalsifiable. If a large-scale observable fails, it can be assigned to a local/global boundary, a different L-level, or a missing sector. If a galaxy residual appears, the regime can be renamed MOND-like after the fact. If the boundary is defined using a fitted potential, $a_0$, a MOND interpolation, a LCDM-derived distance, or the residual being explained, the “regime” is partly built into the measurement and cannot be an independent prediction. The noncommuting limits are also unaddressed: $k\to0$, $g\to0$, high density/screening, large spatial scale, and cosmological-background limits need an explicit order and domain. “Global,” “local,” “IR,” and “screened” are not interchangeable asymptotic operations.

**Exactly what must be frozen to make C13 testable:**

1. **One parent model and typed map.** Freeze a single action/field-equation set, parameter vector, conservation laws, initial and boundary conditions, and the maps from $\Gamma$, $\Box\phi$, $\mathrm dS/\mathrm d\rho$, and the fields to observables. No branch-specific parent actions may be introduced after residuals are seen.
2. **State variables measured independently of the label.** Define a dimensionless control vector before data access, for example $g/a_0$, $\rho/\rho_{\rm crit}$, $k r_*$, redshift, physical scale, environment/external-field strength, and any screening variable such as $|\nabla\Phi|/a_0$. Specify how each is estimated from raw instruments, with units and uncertainty. Do not define a regime by the residual it is supposed to explain.
3. **Numerical regime boundaries.** Freeze the boundary surfaces, transition width/tolerance, spatial and temporal averaging, resolution, global/local pooling rule, and the order of limits. The same classifier must be applied to calibration and holdout data without retuning.
4. **Observable predictions in both sectors.** Derive the LCDM-like predictions for expansion/background/CMB/BAO/LSS/growth/lensing and the MOND-like predictions for galaxy accelerations/RAR/rotation curves from the same frozen parent and parameters. State which quantities are equality limits and which are merely qualitative resemblance.
5. **A discriminating holdout.** Freeze the sample, covariance, nuisance priors, baseline models (including LCDM, MOND or a relativistic completion, and relevant EFT alternatives), likelihood, and falsification threshold. The classifier must predict both labelled behavior and the transition on data not used to define it.

Without those locks, C13 is a gaps argument: a flexible ontology that can accommodate whichever sector is inconvenient. Even after those locks, success would establish a tested embedding, not merely the verbal possibility that two phenomenologies are “candidate regimes.” The formal-limit rows in the review-status section are also not independent evidence; they are the manuscript's own restatement of the claim. (Round-1: F-fals-13, F-mp-8/F-mp-9, F-form-10, F-alt-13, F-para-12/F-para-13.)

### C14 — Corpus scope includes six primary packages plus broader cited packages

**Attack.** The expansion is not fabricated: the repository's DOI inventory and provenance chain do contain 31943361, 31348411, and 31348417, and their titles/roles correspond to the broader LCDM-limit, discrete-gravity, and regime-ontology material. That answers the narrow existence question in the manuscript's favor. It does not answer the scope-governance question.

Relative to the manuscript's stated source-corpus workflow, the broader packages enter late. Table 1 presents six “specific packages this reconciliation draws on,” while the extra identifiers appear only in the review-status section and the later provenance note, chiefly to support C13. No inclusion manifest, time cut, exact package versions, repository commit, or semantic rule says why those three are included while the many other cited EFC packages are excluded. DOI presence proves that a package exists; it does not prove that it was part of the frozen input set, that its claimed role was read before the review, or that the package shares the same physical implementation and normalization.

This creates a post-hoc boundary even if the resulting list is factually present. Either the six-package table was the source corpus, in which case C13 relies on material outside the declared corpus, or the corpus was always broader, in which case the initial inventory was incomplete and the inclusion rule was not frozen. The text cannot claim a fixed-point reconciliation and repair the corpus boundary only after the regime claim is challenged.

**Residual closure required.** Add a canonical manifest containing all included identifiers, titles, versions, commits, hashes, roles, and transitive dependencies, and state the inclusion/exclusion rule before analysis. Label C14 as “current citation scope is non-exclusive” rather than “predefined corpus scope” until that manifest exists. The packages actually present make the expansion traceable, but they do not make it non-post-hoc. (Round-1: F-prov-13/F-prov-14, F-fals-14, F-rep-9, F-alt-14.)

## 3. Single most-lethal falsifying observation

No single observation can falsify the manuscript's purely bibliographic status statements, but the most lethal scientific observation would be a blind, pre-registered joint holdout in which one fully typed EFC parent with frozen units, invariant siren history, $a_0$/SPARC nuisance pipeline, and numerical regime classifier is decisively rejected by the combined large-scale LCDM-like and low-acceleration MOND-like data, while an alternative model passes and fitting the two sectors requires post-hoc parameters or regime boundaries. That outcome would leave an inventory of unrelated package claims rather than a single falsifiable framework with effective regimes.
